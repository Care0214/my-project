# 拾闲小栈 — 校园闲置物品智能交换小程序

基于 **UniApp（Vue2 语法）** 开发的微信小程序，面向高校学生提供闲置物品的**出售、交换、租借、求助心愿**服务。定位是"校园内的二手交易平台"，主打同校区就近交易、AI 智能识别与估价、隐私保护。

## 功能模块

| 模块 | 说明 |
|------|------|
| 登录与实名认证 | 微信授权登录、学校选择 + 校区联动 + 学号验证、资料补全 |
| 首页信息流 | 双列瀑布流卡片、分类入口、校区/排序筛选、猜你喜欢、智能匹配 |
| 多模式发布 | 闲置出售 / 以物换物 / 短期租借 / 求助心愿（求购·求借），支持标签、校区选择、匿名发布 |
| AI 智能识别 | 上传图片调用云函数进行多模态分类，服务不可用时支持手动确认 |
| AI 智能估价 | 按分类 + 新旧程度 + 标题关键词动态估价，价格异常自动拦截 |
| 商品详情 | 多图轮播预览、卖家信息（含学生认证/匿名标识）、收藏、私聊、分享 |
| 租借模块 | 租借市场按校区/排序浏览、租金押金展示、租借详情 |
| 互助广场 | 求购心愿、以物换物、求助帮忙、拼单，点赞/私信 |
| 信用体系 | 信用分总览、等级进度、信用记录、提升指引 |
| 用户主页 | 用户资料、学生认证、在售/出租/互助列表 |
| 隐私保护 | 匿名发布：用随机称号代替昵称，匿名用户不可被反查 |
| 消息中心 | 私信聊天（表情、关联商品）、系统通知、未读统计 |
| 后台管理 | 平台统计、内容审核、用户拉黑/解封、举报处理 |
| 演示工具 | 一键重置数据、一键注入 18 件演示商品（答辩专用） |

## 运行步骤

### 环境要求

- HBuilderX（最新版）
- 微信开发者工具（最新版）
- 微信小程序 AppID（`manifest.json` → 微信小程序配置中填写）

### 运行

1. HBuilderX：文件 → 导入 → 从本地目录导入，选择本项目；
2. 打开 `manifest.json`，确认/修改微信小程序 AppID；
3. 右键项目 → 运行 → 运行到小程序模拟器 → 微信开发者工具；
4. 首次运行按提示配置微信开发者工具路径（`cli.bat`）；
5. 微信开发者工具中勾选"不校验合法域名"（开发调试用），即可正常预览。

> 商品演示图片来自免费图库（Flickr CC），如需替换，直接覆盖 `static/goods/` 下同名文件即可，无需改代码。

## 数据说明（Mock 模式）

- 当前版本**无需后端**：`utils/request.js` 中 `USE_MOCK = true` 时，所有接口走 `utils/mock/` 的模拟后端，包含完整的增删改查（发布、收藏、浏览记录、黑名单、后台管理操作等）；
- **接入真实后端**：把 `USE_MOCK` 改为 `false`，并修改 `BASE_URL` 为后端地址即可，业务代码无需改动（接口约定见 `utils/mock/index.js`）。
- 图片上传接口暂定为 `POST /api/uploads/images`，使用 multipart 字段 `file`，返回 `{ code: 0, data: { url } }`；租借发布接口为 `POST /api/lease-items`。

## AI 识图与估价

### AI 识别（云函数调用）

- `utils/ai-vision.js` 只保存 `enabled` 和云函数名称，不保存模型 API Key。
- 发布页、估价页上传图片后调用 `ai-recognize` 云函数；云函数未部署、超时或识别失败时提示用户手动选择分类。

### 上线方案（云函数）

`uniCloud-aliyun/cloudfunctions/ai-recognize/` 提供了 Key 存服务端的识图云函数：

1. HBuilderX 右键 `uniCloud-aliyun` → 关联云服务空间；
2. 为 `ai-recognize` 配置环境变量 `DASHSCOPE_API_KEY`（和可选的 `VISION_MODEL`）；
3. 上传部署后，前端通过 `uniCloud.callFunction` 调用，详见函数内 README。重新运行 HBuilderX 生成最新小程序产物。

### AI 估价

- 估价接口 `POST /api/price/estimate`：按**分类 + 新旧程度 + 标题关键词**动态计算区间；
- 发布页内置价格异常拦截：低于建议价一半或超过两倍时禁止发布。

## 演示小贴士（答辩用）

- **注入数据**：我的页底部"注入演示数据"，一键生成 18 件覆盖全分类的商品；
- **重置数据**：演示被点乱后"重置数据"恢复初始状态；
- **匿名发布**：发布页打开"匿名发布"，商品将显示随机称号（如"拾光收藏家"）；
- **AI 估价**：发布页输入"华为手机" vs "考研教材"，估价区间会随标题关键词变化；
- **审核闭环**：发布 → 后台管理"内容审核"演示通过/驳回流程。
